## 3. Найденные дефекты (Bug Report)

### BUG-01: Вылет игры при переходе в финал 1-й главы

* **Критичность:** 🔴 Блокер (Blocker)
* **Шаги воспроизведения:**
  1. Начать новую игру.
  2. В сцене в кафе выбрать вариант «Помочь Анне».
  3. Дойти до конца диалога на крыше.
* **Ожидаемый результат:** Запускается кат-сцена финала главы.
* **Фактический результат:** Игра закрывается с ошибкой `FileNotFoundError: assets/bg/bg_roof_night.webp`.
* **Лог / Трейсбек:**
  ```text
  Traceback (most recent call last):
    File "src/scene_manager.py", line 42, in load_bg
      image = pygame.image.load(path)
  FileNotFoundError: No file 'assets/bg/bg_roof_night.webp' found in working directory.
  ```

### BUG-02: Текст выходит за границы диалогового окна

* **Критичность:** 🟡 Незначительный (Minor)
* **Шаги воспроизведения:** Открыть сцену `ch1_intro`, реплика №14.
* **Фактический результат:** Последнее слово длинного монолога обрезается справа.
